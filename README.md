# 🌱 Sustainability Score Calculator

A simple Python program that calculates a sustainability score based on environmental habits.


## Features

- Users can enter the number of plastic bottles they use per week, the number of times they use public transportation per week, and the number of times they recycle per week.
- Calculate a sustainability score.
- Give a rating based on the score.


## How to Run

1. Install Python
2. Download this repository.
3. Run `main.py`


## Example

```text
How many bottles do you use per week? 5
How many times do you use public transport per week? 10
How many times do you recycle per week? 8

Your sustainability score is 21.
Rating: Excellent
```
